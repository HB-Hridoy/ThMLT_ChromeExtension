# ThMLT Chrome Extension

A powerful Chrome extension designed to manage and manipulate themes, colors, and filter specific layouts for [ThMLT AI2 Extension](https://github.com/HB-Hridoy/th-m-l-t). This extension provides comprehensive project management capabilities with intelligent color management and layout filtering tools.

## 🚀 Features

- **🚀 Streamlined Project Control**: Create, manage, and review projects effortlessly
- **🎨 Intelligent Color Management**: Define primitives, map semantics, and switch theme modes to ensure consistent, flexible design
- **📤 Easy JSON Export**: Share project data with a single click  
- **🧹 Smart Layout Filtering**: Extract key UI components from AI2 JSONs for faster workflows
- **📝 Text Formatter**: Edit texts directly from AI2 Builder
- **📊 Project Management**: Import/export JSON data and manage multiple projects

## 📋 Prerequisites

- Google Chrome browser (version 88 or higher recommended)
- Developer mode enabled in Chrome Extensions

## 🛠️ Installation

### Method 1: Manual Installation from GitHub

1. **Download the Latest Release**

    - Open your web browser and navigate to the repository’s **Releases** page:
      [https://github.com/HB-Hridoy/ThMLT\_ChromeExtension/releases](https://github.com/HB-Hridoy/ThMLT_ChromeExtension/releases)
    - Locate the **Latest release** at the top of the page — it is usually clearly marked.
    - Click on the latest release tag or version number to view the release details.
    - Under the **Assets** section, download the appropriate release package for your platform (e.g., `.zip` or `.tar.gz`).
    - After downloading, extract the contents of the archive to your desired folder.

2. **Load the extension in Chrome**:
   - Open Chrome and navigate to `chrome://extensions/`
   - Enable "Developer mode" in the top right corner
   - Click "Load unpacked" 
   - Select the cloned repository folder

3. **Verify installation**:
   - The ThMLT extension icon should appear in your Chrome toolbar
   - Extension should be listed in your Chrome extensions page

## 🎯 Usage

### Key Workflows

#### Project Management
- Create new projects with custom configurations

- Export project settings for sharing or backup

#### Theme & Color Management
- Define color primitives for consistent design systems
- Map semantic colors to primitives
- Switch between light and dark theme modes
- Apply color schemes across your projects

#### Text Editing
- Edit text content directly from AI2 Builder
- Format and style text elements
- Apply consistent typography across projects
